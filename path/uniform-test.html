From a common address to a common quantum test

Origin and a separate separating proof

The question

A single address in the earlier SISA argument worked across many possible read orders. That suggested looking for one test of all pure KD-positive states instead of comparing them one by one.

How it works

  1. The [pure-state tile classification](https://arxiv.org/html/2501.12252v2#S3) describes rank-one KD-positive states using a subgroup, a translate and a character.
  2. In each nonexceptional finite abelian group, pass to the relevant two-prime-factor setting. Design one linear test valid for all the pure tiles, and exhibit a mixed KD-positive state it separates.
  3. Equal primes add oblique subgroup directions, which must also pass the test. Section 5 includes that case and transfers the separation to the full group.

What carries forward

SISA is inspiration, not a premise. The [Bruneton-led 23 November revision](https://github.com/jpbruneton/open_quantum_problems/blob/main/research/entries/kd-z3x3/manuscript/kd-z3x3.tex) already gives the full pure-hull classification, with overlap in its prime-pair and Bell-type approach. A separator by itself does not rule out a finite list of mixed vertices.
